This section is for developers at newsrooms and agencies who extend Lite Site or work on its code. Editors and publishers don't need it to run a Lite Site.

Each page starts with what the thing is for, then shows how to use it. If one of them isn't something the site needs, skip it.

<Cards>
<Card title="Hooks" href="/docs/developers/hooks/" description="Filters and actions that change what a Lite Site page keeps, which content types it covers, and what it prints." />
<Card title="Data" href="/docs/developers/data/" description="What Lite Site stores, and how to remove all of it, for migrations, reports, and clean-up." />
<Card title="Build from source" href="/docs/developers/build-from-source/" description="Compile the plugin from the repository and install it on a local or remote site." />
</Cards>

The plugin's source, issues, and contributing guide live in the [repository](https://github.com/Automattic/newspack-lite-site). It is the full reference for everything these pages leave out.
