By the end of this page, you will have chosen a color and a font for the Lite Site, and know where to add your own CSS.

Appearance is limited on purpose. Pages that load fast on a slow connection matter more than a full brand style. These settings are on the **Appearance** tab of **Lite Site > Settings**.

## Choose a color

<Steps>
<Step>

### Open the Appearance tab

In **Lite Site > Settings**, select **Appearance**.

</Step>
<Step>

### Pick a primary color

Use the **Primary Color** picker. The color is used for links in stories and the divider lines. Until you pick one, it uses the site's primary color, or a default color if the theme has none.

<Screenshot label="The Primary Color picker under Colors, picked out" src="/screenshots/guides/appearance-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Go back to the default

Select **Reset** to return to the site's primary color. The button is off while the site's primary color is in use.

</Step>
</Steps>

## Choose a font

By default, each reader sees their own system font, which costs nothing to load. To use a web font instead, add two things.

<Steps>
<Step>

### Paste the font code

In **Font Embed Code or URL**, paste the embed code or link from a font provider such as Google Fonts. Each extra font or weight makes pages slower to load, so add only what you need.

</Step>
<Step>

### Name the font

In **Body Font**, enter the font name exactly as the provider lists it, for example `Open Sans`. Leave it empty to use each reader's system font.

<Screenshot label="The font embed and Body Font fields under Typography, picked out" src="/screenshots/guides/appearance-2.webp" width={3024} height={1964} />

</Step>
</Steps>

## Add your own CSS

<Steps>
<Step>

### Add the rules

In **Custom CSS**, under **Advanced**, add your own rules. They are added after the built-in styles, so they can override them. Every rule adds to page weight, so keep it short. Lite Site uses your CSS as written. Custom CSS also applies to the offline page, which readers see when they have no connection (see the [FAQ](/docs/guides/faq/#what-happens-if-i-deactivate-the-plugin)). Links that lead away from the Lite Site carry the `lite-site-external` class, so you can style them differently.

<Screenshot label="The Custom CSS field under Advanced, picked out" src="/screenshots/guides/appearance-3.webp" width={3024} height={1964} />

</Step>
</Steps>

## Save

Select **Save** at the top of the screen. Article pages are kept for 15 minutes, so a new color or font can take that long to show on an article that was recently opened. The Lite Site does not keep a copy of the homepage, so changes usually show there sooner.
