By the end of this page, Newspack Lite Site will be active on the site and its menu will be in the dashboard.

<Callout title="On a Newspack site?">
Contact the Newspack support team. They can install and set up Lite Site for you, so you can skip to [Turn on Lite Site](/docs/getting-started/turn-on-lite-site/).
</Callout>

## Before you start

- WordPress 6.6 or later, and PHP 7.2 or later.
- An Administrator account on the site.

## Install it

<Steps>
<Step>

### Download the plugin

Download [newspack-lite-site.zip](https://github.com/Automattic/newspack-lite-site/releases/latest/download/newspack-lite-site.zip). It is always the latest release. Keep the file zipped.

To install an earlier version instead, pick its zip file on the [Releases page](https://github.com/Automattic/newspack-lite-site/releases).

</Step>
<Step>

### Upload it to the site

In the dashboard, go to **Plugins > Add Plugin** and select **Upload Plugin**. Choose the zip file, then select **Install Now**.

<Screenshot label="The Add Plugins screen with the Upload Plugin form open, picked out" src="/screenshots/getting-started/install-the-plugin-1.webp" width={3024} height={1964} />

</Step>
<Step>

### Activate it

When the upload finishes, select **Activate Plugin**. **Newspack Lite Site** appears in the plugins list as active.

<Screenshot label="The Plugins screen with Newspack Lite Site active, its row picked out" src="/screenshots/getting-started/install-the-plugin-2.webp" width={3024} height={1964} />

</Step>
<Step>

### Find the Lite Site menu

A **Lite Site** menu appears in the dashboard sidebar. It holds **RSS** and **Settings**.

<Screenshot label="The Lite Site menu in the dashboard sidebar, showing RSS and Settings, picked out" src="/screenshots/getting-started/install-the-plugin-3.webp" width={3024} height={1964} />

</Step>
</Steps>

To update later, upload a newer zip file the same way, then select **Replace current with uploaded**. Settings and imported entries stay.
